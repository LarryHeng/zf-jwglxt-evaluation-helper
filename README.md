# 正方学生评价自动填写助手

面向正方 `jwglxt` 学生评价页面的 Tampermonkey 自动填写辅助脚本，支持分值选择、当前页测试填写、批量填写保存、分页处理、提交前校验和本机使用统计。

> 本项目主要用于前端自动化脚本学习、DOM 操作实践和浏览器插件式工具开发展示。脚本只在用户主动点击按钮后执行，保存与提交动作均由用户确认或主动触发。

## 项目简介

正方学生评价自动填写助手是一个基于 Tampermonkey 的浏览器用户脚本，适配正方教务系统 `jwglxt` 学生评价页面。脚本通过识别页面中的课程列表、评价项、分值单选框、保存按钮和提交按钮，实现对评价页面的半自动化辅助操作。

项目重点实现了以下能力：

* 自动识别学生评价页面结构
* 自动识别评价项 `radio-pjf` 分值
* 支持目标分数设置
* 支持当前页测试填写
* 支持批量按课程顺序填写并保存
* 支持课程列表分页处理
* 支持可选评语输入，留空则不填写评语
* 保存过程静默执行，不弹窗打扰
* 提交前弹出校验表格，确认评分情况
* 除非用户主动点击提交按钮，否则不会执行提交
* 使用 `localStorage` 记录本机使用统计

## 功能特性

### 1. 当前页测试填写

脚本提供“当前页测试填写”按钮。点击后会先弹窗确认当前页面是否需要填写，并展示当前页评价项数量、已选数量、预计填写数量和目标分数。

填写完成后，脚本会再次弹窗展示：

* 本次实际填写项数
* 当前已选数量
* 100 分项数量
* 分数分布
* 是否填写完成
* 是否立即保存

该功能适合首次使用时单页验证，避免直接批量操作。

### 2. 批量填写并保存

脚本可以按照课程列表顺序依次处理未评价课程。每门课程处理流程为：

1. 选择课程
2. 等待评价内容加载
3. 按目标分数自动选择评价项
4. 校验是否全部填写完成
5. 触发保存按钮
6. 进入下一门课程

批量流程只会保存，不会提交。

### 3. 自动分页处理

当课程列表存在分页时，脚本会先尝试将每页显示数量调整到最大。如果仍然存在下一页，脚本会处理完当前页后自动切换到下一页继续处理。

### 4. 目标分数选择

脚本支持用户输入目标分数。页面中的实际评价档位通常为固定分值，例如：

* 100
* 80
* 60
* 40
* 20

当用户输入的分数没有精确档位时，脚本会选择不高于目标分数的最高可用档位。例如目标分为 90 时，实际选择 80 分档位。

### 5. 提交前校验

脚本不会自动提交评价。只有用户主动点击红色的“提交前校验”按钮后，才会进入提交流程。

提交前会弹出校验表格，展示：

* 当前评价页已选数量
* 当前评价页 100 分数量
* 当前页分数分布
* 课程表读取到的分数
* 是否存在非 100 分课程
* 是否允许提交

校验通过后，用户仍需点击确认提交按钮，脚本才会触发提交。

### 6. 本机使用统计

脚本内置本机使用统计，数据保存在浏览器 `localStorage` 中，不上传到服务器。

当前统计项包括：

* 自动填写次数
* 批量运行次数
* 已处理课程数
* 已处理评价项数
* 自动保存次数
* 提交点击次数
* 预计节省时间

该统计功能可以用于项目展示、使用量说明和效率量化。

## 安装方式

### 1. 安装 Tampermonkey

先在浏览器中安装 Tampermonkey 扩展。

支持浏览器：

* Chrome
* Edge
* Firefox
* 其他 Chromium 内核浏览器

### 2. 新建用户脚本

打开 Tampermonkey 管理面板，点击“添加新脚本”。

### 3. 粘贴脚本代码

将项目中的用户脚本代码粘贴进去，保存后刷新正方教务系统学生评价页面。

建议脚本文件命名为：

```text
jwglxt-evaluation-helper.user.js
```

## 使用方法

1. 打开正方教务系统学生评价页面。
2. 点击左侧未评价课程。
3. 在右侧确认评价内容已加载。
4. 设置目标分数。
5. 可选填写评语，留空则不自动填写。
6. 点击“1. 当前页测试填写”进行单页验证。
7. 确认无误后，可以点击“2. 按顺序填写并保存”进行批量处理。
8. 需要提交时，点击红色“4. 一键提交，先校验”按钮。
9. 校验表格通过后，再手动确认提交。

## 按钮说明

| 按钮          | 功能                       |
| ----------- | ------------------------ |
| 1. 当前页测试填写  | 对当前右侧评价页进行测试填写，完成后询问是否保存 |
| 2. 按顺序填写并保存 | 按课程顺序批量填写并保存，不会提交        |
| 3. 停止任务     | 停止当前批量任务                 |
| 4. 一键提交，先校验 | 弹出提交前校验表格，通过后才允许提交       |
| 5. 页面诊断     | 输出当前页面结构识别结果，便于调试        |

## 页面适配说明

脚本主要适配正方教务系统学生评价页面，核心 DOM 结构包括：

```text
#tempGrid
#panel_content
#btn_bc
#btn_tj
input.radio-pjf
tr.tr-xspj
```

其中：

* `#tempGrid`：左侧课程列表
* `#panel_content`：右侧评价内容区域
* `#btn_bc`：保存按钮
* `#btn_tj`：提交按钮
* `input.radio-pjf`：评价分值单选框
* `tr.tr-xspj`：评价项行

不同学校的正方系统版本可能存在差异，需要根据实际 DOM 结构进行适配。

## 数据与隐私

本脚本不收集、不上传、不发送用户数据。

脚本使用浏览器本地 `localStorage` 保存使用统计，统计数据仅存储在用户本机浏览器中。

本地统计内容包括：

```text
自动填写次数
批量运行次数
已处理课程数
已处理评价项数
自动保存次数
提交点击次数
预计节省时间
```

## 安全设计

脚本在设计上保留了多个防误操作机制：

* 不自动提交
* 保存前进行填写完成度校验
* 提交前弹出校验表格
* 只有用户主动点击提交按钮才会触发提交
* 支持随时停止批量任务
* 当前页测试填写会进行二次确认
